# ARPG

Um projeto experimental de mistério interativo.

Nem toda pergunta precisa de uma resposta imediata. Algumas precisam de investigação, persistência e atenção ao que parece irrelevante.

## Estado

O projeto está em fase inicial. A experiência pública será construída em etapas, com foco em:

- uma interface estática e acessível;
- pistas distribuídas por diferentes meios;
- componentes verificáveis e auditáveis;
- nenhuma coleta desnecessária de dados pessoais.

## Princípios

- Não publicar segredos, chaves privadas ou material de solução no cliente.
- Não afirmar que uma etapa está ativa antes de verificá-la.
- Não realizar pagamentos, publicar pistas externas ou registrar domínios sem autorização explícita.
- Manter a experiência investigável sem exigir que o visitante confie cegamente no autor.

Mais detalhes serão revelados pela própria experiência, no momento apropriado.
