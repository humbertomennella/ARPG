**Um arquivo público de investigação em construção.**

O ARPG está sendo desenvolvido como uma experiência de investigação interdisciplinar: evidências verificáveis, ferramentas, raciocínio, colaboração e uma narrativa que se revela em etapas.

- Modelo de ameaças e runbook documentados.

## Desenvolvimento

Requer Node.js 22+ e npm.

```sh
npm install
npm run dev
npm run build
```

A aplicação atual não exige credenciais nem depende de Supabase para renderizar.
